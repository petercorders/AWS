# AWS Study

AWS SAA-C03 영어 원문 문제를 풀고 기록을 이어가는 정적 학습 사이트입니다. 한국어 안내, 모바일 화면, 전체·미풀이·오답·북마크 필터, 랜덤 20문제, 번호·키워드 검색을 제공합니다.

## 기록 저장

- 답 선택·채점·문제 이동·북마크 변경 시 `localStorage`에 바로 저장합니다. 새로고침하거나 브라우저를 닫아도 같은 주소·같은 브라우저에서 이어서 풀 수 있습니다.
- 계정이나 서버 동기화는 없습니다. 다른 기기·브라우저에서는 **기록 내보내기 → 기록 가져오기**로 옮깁니다. 가져오기는 파일을 검증하고 교체 내용을 확인한 뒤 적용합니다.
- 브라우저 데이터 삭제, 시크릿 모드 종료 시 기록이 없어질 수 있습니다. 중요한 기록은 주기적으로 내보내세요.
- 저장소 사용이 차단되면 실패를 표시하고 재시도·백업을 제공합니다. 읽을 수 없는 기록은 사용자 확인 없이 덮어쓰지 않습니다.
- 정답률과 오답 목록은 문제별 마지막 제출 답 기준입니다. 복수 선택은 정답 집합이 완전히 같아야 맞습니다. 같은 세션의 제출 버튼 중복 클릭은 풀이 횟수에 반영하지 않습니다.

## 로컬 실행 및 검증

Node.js 22 이상과 Python 3이 필요합니다. 외부 패키지 설치나 빌드는 없습니다.

```sh
npm test
npm run serve
```

`http://127.0.0.1:4317`에서 확인합니다. HTML을 파일로 직접 여는 대신 HTTP 서버를 사용하세요. 외부 글꼴을 불러오지 못해도 시스템 글꼴로 동작합니다.

## GitHub Pages

저장소 **Settings → Pages → Deploy from a branch → main / (root)**를 선택하면 됩니다. 별도 빌드가 없고 하위 경로 `/AWS/`에서도 상대 경로로 동작합니다. 공개 예상 주소는 `https://petercorders.github.io/AWS/`이며 Pages 활성화·배포 전에는 열리지 않습니다.

## 문제 출처와 한계

[CarbonRaven/AWS-Quiz-SAA-C03](https://github.com/CarbonRaven/AWS-Quiz-SAA-C03)의 MIT 표기 저장소에서 가져왔습니다. 고정 커밋·수집 시각·제외 목록은 [data/source.json](data/source.json), 원본 라이선스 고지는 [data/UPSTREAM-LICENSE.txt](data/UPSTREAM-LICENSE.txt)에 있습니다.

1,018개 중 선택지 내용이 비어 있는 19개를 제외한 **999문제**를 제공합니다. 형식 검사는 통과했지만 원문의 내용 완전성·최신성·정답 정확성을 보증하지 않습니다. 원본에 해설이 없어 해설은 제공하지 않습니다. 출처 정답과 커뮤니티 최다 투표가 다르면 별도로 표시하며 AWS 공식 문서 검색 링크를 제공합니다. AWS 공식 시험 서비스가 아닙니다.

```sh
npm run data:refresh
```

수집 스크립트는 상위 저장소의 현재 커밋을 고정해 ZIP 하나를 받고 전체 문항을 검사합니다. 검증 실패 시 데이터를 쓰지 않습니다. 갱신 후 제외 목록과 정답 변경을 검토하세요. 문제 ID 기준으로 기록을 연결하므로 이미 저장된 기록에 없는 ID나 선택지가 생기면 자동 덮어쓰기를 막습니다.
