# 한국어 해설 검증

2026-11-12. 사용자 승인 “전체 해설 추가·배포 진행” 범위의 변경이다.

## 내용과 연결

- 999문항에 직접 작성한 한국어 핵심 해설과 실제 선택지 4,127개 각각의 이유가 있다.
- 원문·선택지·정답은 변경하지 않았다. 원본 문항 전체 파일의 SHA-256과 작성 기준을 고정하고, 앱과 빌드 도구가 다른 버전과의 연결을 거절한다.
- 원문 손상, 불완전한 구성, 서비스 수명주기, 출처 정답 의심 사례 206개에 검토 메모를 달았다. 이 수는 '오답이 확정된 문항 수'가 아니다. 그중 24개에는 해설의 권장 답을 별도로 표시했다.
- 공식 문서 고유 링크 491개를 HTTP 검사했다. 오래된 주제 URL이 200 상태의 서비스 첫 화면으로 이동하는 경우도 실패로 취급하고 실제 주제 페이지로 교정했다. 최종 검사에서 HTTP 실패·다른 URL로의 리다이렉트가 없다.
- 외부 한국어 문제집은 번호·선택지 불일치가 있어 복사하지 않았다. 해설은 현재 사이트의 각 문항에 대해 별도로 작성했다. 참고한 문서가 비공식 문제의 답을 인증하는 것은 아니다.

## 기능

- Node 단위 검사 12개 통과. 전체 데이터 연결, 누락·중복 ID, 선택지 대응, 다른 해시, 잘못된 참고 링크, HTML 이스케이프, 출처와 권장 답 분리를 포함한다.
- 기존 브라우저 검사 17개 통과. 현재 선택·문제 위치·오답·북마크·백업·저장 실패·손상 기록 보호가 유지된다.
- 해설 브라우저 검사 10개 통과. 표시·펼치기·저장된 제출 후 재열기·로딩 실패·재시도·검토 문항·PC/390px 모바일·Web Crypto 부재를 확인했다. 실제 스크린샷을 열어 읽기와 가로 넘침을 확인했다.
- 선택지 이유를 실제 화면에서 누락시키는 변이에서 해당 테스트 실패를 확인하고 원복했다.
- 독립 리뷰에서 Web Crypto 부재가 전체 문제 로딩을 막는 문제를 찾았다. 예전 구조로 실패를 재현한 뒤, 해시 계산을 해설 전용 오류 처리 안으로 옮겨 문제·기록 복원은 유지되도록 고쳤다. 같은 브라우저 재현과 회귀 검사로 확인했다.
- `assets/core.js`, `data/questions.json`과 localStorage 저장 키·형식은 바꾸지 않았다.

## 회고 제안

“해설 좀 넣어줘 그래야 공부를 하지”라는 사용자 교정: 문제 풀이 서비스에서 설명은 핵심 학습 흐름이다. 초기 원본에 설명이 없다는 사실을 고지하는 것으로 학습 목적을 충족했다고 보지 않아야 한다. 전역 하네스 규칙은 변경하지 않았다.
