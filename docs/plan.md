# SAA-C03 학습 페이지

사용자 승인: 2026-11-12 “구현 진행해줘”, 새 petercorders/AWS 저장소, 읽기 쉬운 화면과 학습 기록 보존.

1. 공개 문제 JSON을 고정 커밋에서 수집하고 출처·라이선스를 보존한다. verify: 전체 ID 중복, 문항·선택지·정답 참조 유효성 검사.
2. 빌드 없는 HTML/CSS/JavaScript로 전체·미풀이·오답·북마크, 랜덤 20문제, 검색, 복수 선택 채점을 구현한다. verify: 실제 데이터 전수 검사와 채점 단위 테스트.
3. 선택 중인 답, 제출 결과, 현재 문제 순서까지 localStorage에 즉시 저장한다. verify: 새로고침 복원, 쓰기 실패·손상 데이터 처리, 백업 왕복·잘못된 백업 거절 테스트.
4. 백업 가져오기는 검증 후 미리보기와 명시적 적용을 제공한다. 취소하면 기존 기록 유지, 적용 시 전체 교체. 파일을 읽는 사이 새 파일을 고르면 이전 요청을 무시하고 가져오기 대화상자가 열린 동안 학습 입력을 차단한다. 저장 실패 시 메모리에 남겨 재시도·내보내기 지원. 이중 제출은 세션 결과로 차단.
5. PC·모바일 브라우저에서 선택→채점→이동→새로고침→복원 동선을 확인한다. verify: 실제 화면·콘솔·좁은 화면 넘침 검사 및 핵심 채점 변이 확인.
6. 변경 검토 후 로컬 커밋. push와 Pages 활성화는 별도 확인.

plan-check: 서버 없음 — 학습 기록은 브라우저에만 저장하고 문제 파일은 정적 제공한다.

결과를 모를 때: localStorage 쓰기가 실패하면 저장되지 않음을 계속 표시하고 메모리의 기록은 유지한다. 같은 현재 기록을 다시 저장하거나 JSON으로 내보낼 수 있다. verify: 저장소 쓰기 거절 단위 테스트와 브라우저 재시도 동선.

저장 범위: 같은 브라우저·같은 주소에서 유지. 브라우저 데이터 삭제나 시크릿 모드 종료, 다른 기기는 자동 동기화하지 않는다. JSON 백업으로 이동 가능. 정답은 출처 기준이며 커뮤니티 투표와 다를 수 있다. 원문에 없는 해설을 생성한 것처럼 표시하지 않는다.
