# 구현 검증

2026-11-12, `feat/saa-study` 로컬 작업 기준. GitHub push와 Pages 배포는 아직 하지 않았다.

- Node 기본 테스트 7개 통과: 복수 정답 완전 일치, 저장/백업 왕복, 이중 제출 방지, 오답 재학습, 백업 검증, 저장소 오류, 검색/필터, 전체 데이터 형식.
- 실제 Orca 브라우저 검사 17개 통과: 선택→새로고침→복원, 제출·북마크·문제 위치 보존, 백업 취소·적용·불량 파일 거절, 복수 선택, 저장 실패·재시도, 손상 기록 보존·교체 승인, 랜덤 20개 중복 없음, 미제출 제외, 검색/빈 결과.
- 데스크톱과 390px 모바일 홈·풀이 화면에서 가로 넘침 없음. 실제 스크린샷 확인. 브라우저 콘솔 오류 없음.
- 채점의 `every`를 `some`으로 바꾸는 변이에서 테스트 실패를 확인하고 원복했다. 일부 정답만 겹치는 답을 정답으로 오인하는 변경을 검사한다.
- JavaScript 구문, Python 구문, 계획 점검, diff 공백 점검 통과.
- 자체 리뷰: 가져오기 전 검증과 확인, 비동기 파일 선택 순서, 손상 저장소 덮어쓰기 방지, 외부 텍스트 HTML 이스케이프, 초기 로딩 중 입력 보호 확인.

## 범위와 한계

데이터 999개는 형식 검사를 통과한 수다. 정답의 의미나 원문 누락을 전수 검수한 수는 아니다. 원본 저장소에서 선택지가 빈 19개는 제외했다. 클라우드 동기화·문제 번역·생성 해설은 포함하지 않는다.

브라우저 검사 재실행은 로컬 서버를 켜고 Orca에서 해당 주소를 연 뒤 `python3 scripts/browser_check.py --page <browserPageId>`로 실행한다. 로컬 QA 주소만 허용하고 기존 저장 값을 검사 전 보관했다가 종료 시 복원한다.

## 회고 제안

사용자 정정 “저장소는 너가 만들어야해 AWS로 만들어줘”: 로컬에서 발견한 유사 학습 저장소를 대상 저장소로 단정했다. 다음에는 발견 사실과 대상 추정을 구분해 설명할 것. 전역 규칙 반영은 하지 않았다.
