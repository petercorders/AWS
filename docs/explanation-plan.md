# 999문제 한국어 해설

2026-11-12 사용자 승인: “전체 해설 추가·배포 진행”. 기존 사이트의 전체 해설·선택지별 이유·AWS 공식 문서 근거 추가 및 Pages 배포를 포함한다.

1. 기존 999문항 각각을 읽고 핵심 해설과 모든 선택지별 이유를 한국어로 작성한다. 참고 자료는 AWS 공식 문서로 제한하고, 원본 정답과 다른 판단·원문 손상·시점에 따른 기능 변경은 검토 표시로 남긴다. verify: 전체 ID/선택지 일치와 내용 검토.
2. 원본 질문 파일의 SHA-256과 해설 버전을 연결한다. 문제 데이터가 갱신되면 다른 문항에 해설을 붙이지 않고 안내한다. verify: 잘못된 해시·중복·누락·잘못된 공식 링크 거절 테스트.
3. 정답 확인 아래 핵심 해설, 정답·내 선택 이유, 다른 선택지 이유, 관련 공식 문서를 보여준다. 원본 정답과 해설 판단은 구분하고, 학습 기록과 채점 기준은 기존 값을 보존한다. verify: 단일/복수 정답·검토 표시·HTML 이스케이프·PC/모바일 검사.
4. 해설을 못 받으면 문제 풀이는 계속 제공하고 해설 다시 시도를 안내한다. 결과를 모를 때: 해설은 읽기 전용 파일이며 로딩 실패는 미리보기와 실제 사이트에서 명시한다. 다시 시도는 해설 파일만 재요청하고, 이중 입력은 로딩 중 버튼 비활성화로 막으며, 학습 홈/뒤로 이동은 학습 기록을 바꾸지 않는다. verify: 해설 읽기 실패와 재시도·진도 보존.
5. 내용과 기능 검증 후 커밋·사용자가 승인한 Pages 배포를 진행하고 실제 URL에서 확인한다.
